# Home-Cabang (TOYHUB.CABANG)

Ekosistem Website Modern Terpusat untuk Multi-Cabang, Waralaba (Franchise) & Jaringan Toko Mainan, Hobby & Collectibles Indonesia.

## 🚀 Fitur Utama
- **Arsitektur Multi-Cabang & Multi-Tenant**: Pengelolaan ribuan katalog mainan dari HQ terpusat ke seluruh gerai cabang kota (Jakarta, Bandung, Surabaya, dll).
- **Floating Quick Filter Dock**: Pencarian instan berdasarkan kota cabang, kategori mainan, skala gerai, serta visualisasi rating.
- **Interactive Branch Simulator**: Simulasi detail gerai per kota lengkap dengan katalog siap kirim, integrasi peta visual, dan router WhatsApp CS cabang lokal.
- **15 Template E-Commerce & Showroom Toko Mainan**: Mulai dari Brick & Modular, Dolls & Luxury Plushie, Action Figure & Anime, Art Toys & Blind Box, hingga Montessori Edu Toys.
- **Modern Architectural Aesthetics**: Desain berstandar tinggi berbasis Deep Oceanic Teal, Soft Mint Slate, dan Vibrant Coral Accent.
- **Model Bisnis Fleksibel**: Dukungan Franchise, Multi-Mall Chain Store, hingga Retail Kolektor Blind Box & Pop-Mart.

## 🛠️ Tech Stack
- **Frontend**: React.js (Vite), Modern Vanilla CSS Design System, Lucide Icons & Responsive SVG
- **Backend / API**: Express.js & Node.js
- **Assets**: Dynamic Canvas Network, Optimized Architectural Showcase Imagery

## 💻 Menjalankan Secara Lokal
```bash
# Clone repositori
git clone https://github.com/fadhlurr01/Home-Cabang.git
cd Home-Cabang

# Install dependensi
npm install

# Jalankan development server
npm run dev:all
```
Buka browser di `http://localhost:5173`.
